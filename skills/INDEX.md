# Skills Index

Project-specific skills for this repository.

## Available Skills

| Skill | Use It For |
| --- | --- |
| `repo-orientation` | Find the right script, path, or doc before editing or running work. |
| `prompt-rendering` | Render and inspect prompts from specs and cartridges. |
| `project-generation` | Run project generation and manage session resume behavior. |
| `evaluation-workflow` | Run static evaluation and merged benchmark results. |
| `e2e-testing` | Run compile-first runtime validation and triage runtime failures. |
| `docs-maintenance` | Keep docs, status, and output examples aligned with reality. |

## Suggested Routing

- Start with `repo-orientation` if you are unsure where a task belongs.
- Use `prompt-rendering` before generation work.
- Use `project-generation` for workspace creation and retry logic.
- Use `evaluation-workflow` for static or merged scoring work.
- Use `e2e-testing` for runtime failures, builds, and container startup issues.
- Use `docs-maintenance` for any claim, table, or path shown to users.
