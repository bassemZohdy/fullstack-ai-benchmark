# Overview Specification

Build a full-stack todo application for the selected backend and frontend stack.

The application must include:

- Todo CRUD operations
- A user-facing frontend for listing, creating, updating, completing, and deleting todos
- A backend API for todo persistence
- Basic validation and error handling
- Docker support
- Kubernetes manifests
- Environment configuration example
- Project README with local run instructions
- The project must compile successfully and start in development mode with `docker compose up`
- Use separate top-level `backend/` and `frontend/` directories for the generated project
- Place all backend files under `backend/` and all frontend files under `frontend/`

Use the selected backend and frontend cartridges for implementation details.
