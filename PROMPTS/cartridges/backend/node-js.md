# Backend Cartridge: Node.js

- Use Node.js with Express and npm for package management.
- Keep the project structure simple: routes, controllers, and a data layer. Avoid unnecessary abstraction.
- Build a minimal compileable API first, then add persistence and tests.
- Provide REST endpoints for todo CRUD with straightforward request and response models.
- Include validation and JSON error responses.
- Include CORS configuration for the selected frontend.
- Include automated tests only where they improve confidence without delaying the first working build.
- Include environment-based configuration, but do not add optional infrastructure unless the spec requires it.
