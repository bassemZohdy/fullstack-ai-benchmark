# Frontend Cartridge: React

- Use React with TypeScript.
- Prefer Vite as the build tool with the current stable React template; keep the first pass compileable.
- Prefer the package versions emitted by the generated scaffold; do not invent or override package versions in the first pass.
- Provide todo list, create, update, delete, and completion interactions.
- Use a service/API layer for backend calls with fetch or axios.
- Use React hooks for state management; keep state handling simple unless the spec requires more.
- Use React Router for navigation if multiple views are needed.
- Keep the component tree simple and organized (e.g., components/, services/).
- Include loading, empty, and error states.
- Include basic component tests only after the app compiles cleanly.
